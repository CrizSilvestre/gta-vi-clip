# GTA VI Clip Studio — sitio

Página de inicio, política de privacidad y términos de **GTA VI Clip Studio**, la app de escritorio con la que el canal
de YouTube **GTA VI CLIPs** prepara y sube sus Shorts. Publicado con GitHub Pages:
https://crizsilvestre.github.io/gta-vi-clip/

Canal de fans, no afiliado a Rockstar Games ni a Take-Two Interactive.
